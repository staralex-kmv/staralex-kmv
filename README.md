# Алексей Зайцев — ИИ-агенты для бизнес-процессов

Строю ИИ-агентов и автоматизации, которые работают в реальных процессах компаний: документы, отчётность, заявки, поддержка клиентов.
Больше 20 лет в продажах и дистрибуции FMCG (AB InBev, Mars, Henkel, Royal Canin), руководил IT-направлением дистрибьютора: 1С, WMS, «Меркурий», обмены с поставщиками.

**Принципы:** человек подтверждает значимые действия · конфиденциальные данные обрабатываются локальными моделями · у каждого решения посчитана стоимость эксплуатации · модель не выдумывает, если данных нет.

## Проекты

| Проект | Что делает | Стек | Статус |
|---|---|---|---|
| **Агент заполнения договоров** | Шаблон .docx + карточка партнёра → готовый договор. Оркестратор (Claude Code) маршрутизирует документ по реестру, формирует лист мастер-данных и детерминированный скрипт заполнения; исполнитель — локальная модель. Проверка результата в 5 этапов. Данные не уходят в облако. | Python, python-docx, Ollama (Qwen 2.5), Open Interpreter | работает |
| **Отчётность и расчёты с партнёром** | Ежемесячный цикл: забирает выгрузки, заполняет формы, считает оплату, готовит черновики писем. | Python, openpyxl, Mail | работает |
| **Бот-консультант по базе документов** | Отвечает на вопросы по загруженным документам; если ответа в базе нет — прямо говорит об этом. | FastAPI, OpenAI Responses API, File Search | работает |
| **Бот акции «Баллы за чеки»** | Продавцы присылают фото чеков, бот начисляет баллы за товары акции. Конвейер: чтение фискального QR → проверки (повтор по ФН+ФД+ФП, период акции, привязка кассы к точке по ИНН и адресу) → распознавание позиций → сопоставление с SKU → баллы. Распознавание — бесплатный воркер на Mac mini (Apple Vision), при его молчании дольше 2 минут — резерв Yandex Vision (≈0,13 ₽ за фото). Спорные чеки — модератору, отчёт Excel для менеджеров. | Python, SQLite, zxing-cpp, Apple Vision, Yandex Vision, Telegram, MAX, nginx | пилот |
| **Трек ВУЗ** | Платное исследование поступления: анкета → направление → вузы в городах абитуриента → данные с официальных сайтов (бюджет, целевая, стоимость, проходной балл) → два PDF: отчёт и план подготовки. Правило — ни одного выдуманного значения: база из 22 000+ проверенных фактов с источниками, движок качества данных и эталон для регрессии. | Python, aiogram, Telegram, MAX, Т-Банк, Next.js | работает |
| **Бот для отдела продаж дистрибьютора** | Торговая команда получает в мессенджере условия, акции и планограммы; ежемесячно — выгрузка пользователей, расчёт оплаты и черновики писем партнёру. | LEADTEX, Telegram, MAX, Python | работает |
| **[AI-диагност авто](https://github.com/staralex-kmv/Ai_Diagnost_Avto)** | VIN + коды ошибок → диагноз и PDF-отчёт с бюджетом ремонта. Продакшн-версия — бот в Telegram и MAX с оплатой и сайтом. | Python, LLM, ReportLab, ЮKassa | работает |
| **Надёжный приём заказов** | Проверка заявки, защита от дублей, разбор текста ИИ, запись в базу, уведомление. Резервная модель при отказе основной, тревога при полном сбое. | n8n, YandexGPT, GigaChat, NocoDB | проект |
| **ИИ-квалификация заявок в CRM** | Модель раскладывает заявку по 4 маршрутам, повышает приоритет по словарю срочности, ставит менеджеру дело с черновиком ответа. | n8n, Битрикс24, LLM | проект |
| **Бот для мероприятий «Я на ивенте»** | Один бот для конференции сразу в Telegram, MAX и ВКонтакте: вход по ссылке, программа и события, вопросы лектору, «написать менеджеру», напоминание в календарь, маршрут. Веб-панель с ролями для организатора и отчёты в Excel. Согласия по 152-ФЗ; после мероприятия данные участников удаляются каскадно. | Python, aiogram, FastAPI, SQLite, Jinja2, argon2 | работает |
| **Контент-завод** | Одна новость про ИИ → готовые посты в JSON для Telegram, Instagram, X, TikTok и ВКонтакте; автопостинг во ВКонтакте. | Claude Code (навыки), VK API | выполнено |
| **Локальный ИИ-контур** | Распознавание речи, OCR, исправление текста, обезличивание ПДн — офлайн на Mac. | whisper.cpp, Qwen2.5-VL, Ollama | работает |
